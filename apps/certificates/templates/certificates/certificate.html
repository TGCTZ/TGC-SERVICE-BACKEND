{% comment %} The gemstone identification report, as the lab issues it: A4 landscape, three columns, one page. Layout is absolute, in millimetres measured from the paper edge - not flow, and not flexbox. A certificate is a *form*: the stamp box has to sit in the same place on every sheet whether the comments field is empty or three lines long, so the boxes are placed first and the data pours into them. Flexbox is used only to centre content *inside* a box, never to decide where a box goes. (The previous version sized the page with `height: 100%` against a body of auto height, which collapses; the columns then had no space to grow into and everything crowded into the top half of the sheet.) The coordinates are collected in the two tables below - PAGE BANDS and the per-column blocks - so the layout can be re-proportioned by editing numbers rather than by unpicking nested boxes. Every fixed box is `overflow: hidden`: a certificate with far more findings than the form allows for degrades by truncation, not by printing over the QR code. CSS is inline rather than a linked stylesheet, and every image is a data: URI passed in from services/assets.py. Both for the same reason - the renderer is handed a bare HTML string with no base_url, so there is nothing to resolve against the filesystem and nothing that depends on collectstatic having run. Values come from the certificate's *_snapshot columns, never from the live report. Nothing here carries a placeholder default: a finding nobody recorded prints an em dash, because a certificate that invents a plausible figure is worse than one that admits it has none. "Please see the back side" refers to pre-printed stationery. There is no second page, and there never was one in the system this is ported from. {% endcomment %} {{ certificate.certificate_number }}
